# X Guard

一个在 Chrome 中运行的 X 回复过滤扩展。选中你关心的条件，让程序检查回复作者；命中后可以记录、折叠或屏蔽，并保留可核查的记录。

**v0.3.0 · 中文界面 · Manifest V3 · MIT**

## 安装

1. 点击仓库右上角 **Code → Download ZIP**，下载后解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 打开已登录的 [X](https://x.com)，刷新页面，再从扩展菜单打开 **X Guard**。

无需 Node、npm 或 X API 密钥。也可以从 Releases 下载打包版本并解压安装。

## 三步开始使用

### 1. 点击色块，选择参与判断的条件

陶土色表示已选中，浅色表示未选中。没有勾选框；色块本身就是开关，也支持键盘操作。

| 条件 | 如何判断 |
| --- | --- |
| 香港 / 日本地区 | X 的 “About this account” 显示为香港或日本 |
| China Android App | “Connected via” 显示为 China Android App |
| 粉丝少于 10 | 可读取的粉丝数为 0–9 |
| 反复明确辱骂 | 最近最多 20 条本人回复中，取得至少 10 条；明确辱骂至少 5 条且占比至少 50% |

**默认在已选条件中命中任意两项即符合。至少保留两个条件。未选中的条件不计入命中数，未知信息也不算命中。**

例如，选中“China Android App”和“粉丝少于 10”后，只有这两项同时满足的账号才符合；无需再满足地区或辱骂条件。全部四项选中时，其中任意两项满足即可。

从旧版升级时会保留原规则的命中门槛；提示文字显示实际门槛。首次修改条件色块后采用两项门槛。

### 2. 选择命中后的动作

- **只记录证据**：先查看匹配结果，不修改 X 屏蔽名单。首次安装默认使用此模式。
- **折叠该账号的回复**：在当前浏览器的帖子详情页折叠符合规则的作者回复，可展开阅读。
- **自动屏蔽账号**：复核账号资料和数字 ID 后提交屏蔽，再检查 X 返回的状态。

更改色块、处理动作或白名单会自动保存并暂停检查。点击**启动自动检查**后，才按新配置继续工作。

### 3. 启动检查

在 X 页面打开扩展并点击**启动自动检查**。程序会创建后台工作标签页，从当前帖子评论区和中文回复搜索中收集作者、自动翻页、逐个核验，不需要一直手动滚动。

面板显示本轮已确认屏蔽、已核验、等待队列及已发现作者数。自动屏蔽模式每轮目标为 1,000 个新屏蔽；已有屏蔽不会重复计数。目标不是完成保证，取决于实际匹配数量、页面可用性和平台限制。

## 管理与撤销

- **立即暂停**：停止后续提交。已经发给 X 的请求仍会完成状态核验。
- **白名单**：输入用户名，空格或换行分隔。白名单、已关注账号、本人及已屏蔽账号都会跳过。
- **核验记录**：查看命中条件、资料、错误和可用的文本证据；扩展已确认的屏蔽可点击**撤销屏蔽**，撤销后自动加入白名单。
- **导出记录**：导出本机 JSON，包含配置、记录和当前任务状态。文件可能包含你的账号与筛选记录，分享前请自行检查。
- **更多选项**：手动加入用户名，或点击**加载程序更新**重新加载本地版本。

首次安装或更新后请刷新 X 页面。重新加载扩展或重启浏览器会停止运行，需要再次启动。保存的配置和本地核验记录不会因此清除；本轮计数会在新启动时重置。

## 更新现有安装

用新版本文件覆盖原扩展文件夹，打开面板底部 **更多选项 → 加载程序更新**。随后刷新 X 页面，检查配置并启动。也可在 Chrome 扩展管理页使用重新加载按钮。

## 数据与权限

- 只请求 `https://x.com/*` 的页面访问权限，以及扩展存储和定时调度权限。
- 使用当前浏览器的 X 登录会话，不索取或保存密码、Cookie、API 密钥。
- 无自建服务器、遥测或外部语言模型请求。扩展运行时不下载字体或脚本。
- 配置与记录保存在扩展本机存储。保留已确认屏蔽、撤销及结果未知的记录，以及最近 2,000 条普通核验结果；每条记录最多保存 5 段、每段 600 字符的文本证据。
- 卸载扩展不会解除 X 账号中已经完成的屏蔽。

## 使用边界

地区标签是 X 提供的地区信息，不是实时 IP；地区、客户端和粉丝数不能证明一个人的职业、国籍或身份。辱骂判断使用保守规则，不是经过准确率评估的通用分类模型，可能漏检或误判。

程序依赖 X 网页结构与搜索索引，主要支持英文和部分中文界面。限流、登录变化、结果未知、反复读取失败或来源耗尽时会停止；请查看面板原因。不会绕过平台验证或限制。

## 开发与测试

需要 Node.js 22 或更新版本：

```sh
npm ci
npm test
```

运行时使用原生 JavaScript，无第三方运行时依赖。`linkedom` 只用于测试。

| 文件 | 用途 |
| --- | --- |
| `core.js` | 条件配置、迁移与判断 |
| `dom.js` | 页面资料与作者提取 |
| `content.js` | 页面读取、折叠及受控点击 |
| `background.js` | 主动扫描、队列、复核和记录 |
| `state.js` | 去重与运行状态判断 |
| `panel.html` / `.css` / `.js` | 暖纸风格面板和交互 |

视觉采用暖白、陶土色、衬线标题与无衬线控件组合，使用系统字体回退；项目不隶属于 Anthropic 或 X。

设计研究参考：[LocaleFence](https://github.com/ssupt/LocaleFence)、[X Comment Blocker](https://github.com/amahteru/x-comment-blocker)、[BlueLiteBlocker](https://github.com/BlueLiteBlocker/BlueLiteBlocker)。实现独立编写。
